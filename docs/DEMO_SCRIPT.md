# Скрипт демо для защиты / Defense demo script

**Что показывать:** `DrawToSTEP.exe` (скачать в Releases) или из исходников `python -m app.main --demo`.
**Время:** 30–40 секунд. **Что говорить:** коротко, по шагам ниже.

## Подготовка (до защиты)

- Скачать `DrawToSTEP.exe` из [Releases](../../releases) на флешку (ничего не нужно устанавливать, Python не нужен).
- Или собрать из исходников: `pip install -r requirements.txt`, запуск — `python -m app.main --demo`.
- Регенерить скан (если показываете скан-ветку): `python data/examples/real/generate_real_examples.py` (создаёт `scan_test.png`, он не в git — это нормально).
- Прогон `python -m app.main --headless data/examples/flange_shaft_demo.pdf --out exports` — контроль, что сборка живая.

## Ход защиты (30 секунд)

1. **Запуск.** «DrawToSTEP — офлайн-конвертер чертежей тел вращения в STEP. Никаких облаков: чертёж не покидает эту машину». Окно открывается на экране загрузки; в демо-режиме пример **уже загружен** (вал Ø50–Ø90–Ø40, масштаб 1:1, А3).
2. **Экран «Размеры» (Verification).** «Все размеры распознаны. 7 размеров, уверенность 0.85–0.95, строки зелёные. Ни один размер не применяется без подтверждения человека». Показываете список, масштаб чертежа определён автоматически (ГОСТ 2.302, 1:1).
3. **Сборка.** Нажимаете «Подтвердить и собрать 3D» → «Вращай мышью» — вращаете модель; «Объём 870,220.9 мм³» на экране.
4. **Экспорт.** «Скачать .STEP» / «Скачать .STL» — файл открывается во FreeCAD / КОМПАС-3D (Файл → Открыть).
5. **Скан (если спросят).** Удалите пример, перетащите `data/examples/real/scan_test.png` → «Скан грязный: 200 DPI, поворот 2.5°, шум. Конвейер сам выравнивает, векторизует, читает OCR. Диаметры RapidOCR не смог прочитать (теряет символ Ø) — но конвейер **предложил значения по геометрии**: Ø60/Ø40/Ø30/Ø12, уверенность 0.85, все помечены „предложено по геометрии — подтверди“». Кликаете «Подтвердить» ×4 (1 клик каждый) → «Подтвердить и собрать 3D» → 3D. «Погрешность объёма +0.26%».

## Честные ограничения (если спросят — говорим прямо)

- STEP — твердотельное **B-rep**, не история построения (редактирование истории — задача CAD-пакета).
- Скан 200 DPI «съедает» ~3 мм по длинам; линейные размеры по скану проверяются с допуском ~3 мм (PDF — 0.05 мм).
- OCR на шумных сканах теряет символы (Ø → «060»); такие размеры никогда не применяются без явного подтверждения — жёлтая строка + «Подтвердить».
- Человек обязателен: «Подтвердить и собрать 3D» заблокирована, пока не подтверждены все размеры.
- Только тела вращения, один главный вид. Призматические детали, резьбы, PMI — Phase 2.

## Откат (если exe не стартует)

- Работает из исходников: `python -m app.main --demo` (та же ветка кода, что в exe).
- `python -m app.main --headless data/examples/flange_shaft_demo.pdf --out exports` — печатает STEP/STL в консоль без GUI.
- Лог ошибок: exe собирается без `--debug`; проблемы глобально: нехватка прав установки — ставить в папку пользователя, не в Program Files.
