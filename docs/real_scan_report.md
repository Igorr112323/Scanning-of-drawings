# Отчёт по скану — шаблон / Real scan report (template)

Этот файл перезаписывается командой:

```bash
python -m core.benchmark_real --scan data/examples/real_scans/my_scan.png
# с эталоном объёма:
python -m core.benchmark_real --scan data/examples/real_scans/my_scan.png --gt path/to/ground_truth.json
```

См. инструкцию по сканированию: `data/examples/real_scans/README_RU.md`.

## Честные ограничения

- Неуверенные размеры НИКОГДА не применяются без явного подтверждения в интерфейсе.
- Растр 200 DPI съедает ~3 мм; при DPI < 300 точность по длинам ~3 мм.
- OCR на зашумлённых сканах теряет символы (Ø → ведущий ноль); такие размеры подтверждаются в UI.
- Фаски применяются из размеров 2×45°; STEP — твердотельное B-rep.
