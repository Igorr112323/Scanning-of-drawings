# Example drawings / Примеры чертежей

## Что здесь лежит

| Файл | Что это |
|---|---|
| `flange_shaft_demo.pdf` | Синтетический «вал ступенчатый»: А3, масштаб 1:1, тела вращения: Ø50 × 120 / Ø90 × 80 (фланец) / Ø40 × 100, общая длина 300 мм |
| `generate_example.py` | Генератор этого PDF. Пример **создан кодом**, а не скачан — воспроизводимо и лицензионно чисто |

Перегенерировать пример:

```bash
python -m data.examples.generate_example          # → data/examples/flange_shaft_demo.pdf
```

## Как устроен пример

- Полное симметричное очертание (полусечение + нижняя половина), толщина контурной линии 0.7 мм
- Осевая линия — штрихпунктирная (GOST 2.303), распознаётся как `AXIS`
- Размерные линии — тонкие сплошные, стрелки — залитые треугольники (парсер их игнорирует)
- Размеры: Ø50/Ø90/Ø40 (размерные линии через деталь со стрелками),
  цепочка линейных 120/80/100 и габарит 300 — под видом
- Масштаб **1:1** → солвер не должен менять масштаб и не должен находить противоречий

## Как добавить свой чертёж

1. Экспортируй из КОМПАС: **Файл → Сохранить как → PDF**, масштаб в листе — любой из ряда ГОСТ 2.302
   (1:2, 1:2.5, 1:4, 1:5, 1:10, 2:1, 2.5:1, …) — солвер определит его автоматически.
2. Положи PDF в эту папку (или просто открой его через «Выбрать файл» в приложении).
3. Следи, чтобы:
   - тело вращения было с одной главной осью (вал/втулка/фланец/кольцо);
   - осевая линия была именно штрихпунктирной (в КОМПАС — слой «Осевые»);
   - размеры были набраны шрифтом, распознаваемым как Ø/R/M (КОМПАС делает это автоматически).

## Почему только синтетика в репозитории

Чертежи предприятий — это ноу-хау. В репозиторий кладём только сгенерированные
или явно обезличенные примеры; производственные чертежи — через issues Phase 2
(датасет), с согласия держателя.
